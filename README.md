# WraithDesk

WraithDesk is a mixed-reality workspace that connects a Meta Quest headset with a Windows PC over a trusted local network. It is developed by Insane Zombie Studio.

## PC companion preview

[Download WraithDesk PC 0.30.10 and its SHA-256 checksum](https://github.com/Insnzmb/WraithDesk/releases/tag/v0.30.10). A compatible Quest app and a supported hardware H.264 encoder are also required. This preview is under active testing; Windows may display an unrecognized-app warning because the installer is not Windows Authenticode signed.

The Windows companion uses FFmpeg under LGPL 2.1 or later. Its notices, corresponding source and rebuild materials are included in the installer and [release downloads](https://github.com/Insnzmb/WraithDesk/releases/tag/v0.30.10). Third-party licence rights remain in effect. Application source and signing credentials are not published.
